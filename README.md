# .github

This repo holds organization-level GitHub configuration for the [`avinash-matrixgard`](https://github.com/avinash-matrixgard) GitHub organization (operated by [MatrixGard](https://matrixgard.com)).

The most-visible file here is [`profile/README.md`](profile/README.md) — GitHub renders that as the org's landing page at https://github.com/avinash-matrixgard.

If you're looking for MatrixGard's actual products, you want one of the other repos in the org — start with [aws-startup-security-baseline](https://github.com/avinash-matrixgard/aws-startup-security-baseline).

---

## What lives here (and what could)

Currently:

- [`profile/README.md`](profile/README.md) — the org-page landing copy

Future / room to grow:

- `.github/ISSUE_TEMPLATE/` — org-default issue templates inherited by every repo without its own
- `.github/PULL_REQUEST_TEMPLATE.md` — org-default PR template
- `.github/CODE_OF_CONDUCT.md` — org-wide CoC
- `.github/SECURITY.md` — coordinated-disclosure policy (we'd want this once any repo here ships production-grade security tooling)
- `.github/FUNDING.yml` — sponsor links (not currently used)
